# Web Lab ELINS

Frontend website Laboratorium Riset Elektronika dan Instrumentasi.

## Requirement

- Node.js
- npm

## Cara Menjalankan Project

1. Clone repository

git clone https://github.com/nijika1ji/nyoba_web.git

2. Masuk ke folder project
misal cd nyoba_web

3. Install dependency
npm install
   
4. Jalankan project
npm run dev

5. Buka di browser
http://localhost:5173
